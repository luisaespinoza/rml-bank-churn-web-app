# Bank Churn Minimal Deployable ML - Browser Prototype

This is the static browser frontend for the Tiny ANN bank-churn deployment demo.

The app intentionally has no backend, no API keys, and no paid cloud inference service. It expects the training repository to produce the deployment artifacts first.

## Canonical public artifact layout

Use one artifact root:

```text
public/artifacts/
├── deployment/
│   ├── best_model.onnx                 # required, export from trained .pt checkpoint
│   ├── preprocessing_schema.json       # required, fitted train-only preprocessing metadata
│   └── deployment_manifest.json        # optional metadata
└── ort-wasm/
    └── ...                             # generated by npm run copy:ort
```

Do not also use `public/ort-wasm/`. The app points ONNX Runtime Web to:

```js
./artifacts/ort-wasm/
```

## Important ONNX handoff

The current training snapshot names `artifacts/deployment/best_model.onnx` as the browser model artifact, but if the trained `.pt` checkpoint has not yet been exported to ONNX, the file will not exist yet.

The browser app cannot create `best_model.onnx`. Export the Tiny ANN from the training repo first, then copy it here:

```text
public/artifacts/deployment/best_model.onnx
```

## Setup

```bash
npm install
npm run copy:ort
npm run check:artifacts
npm run dev
```

`npm run check:artifacts` will fail until `best_model.onnx`, `preprocessing_schema.json`, and the ORT wasm files are present.

## Build

```bash
npm run build
```
